# Descripción

Excel Unifier Pro nace para resolver un problema muy común en el trabajo con datos: tener decenas de archivos Excel o CSV sueltos —a veces con distintas codificaciones, distintas hojas, o generados por sistemas distintos— y necesitar consolidarlos en un único libro sin hacerlo hoja por hoja a mano. La herramienta se distribuye como una aplicación de escritorio con interfaz gráfica en Tkinter, pensada para que un usuario no técnico pueda arrastrar sus archivos o una carpeta completa, elegir cómo quiere combinarlos y obtener el resultado en segundos.

Internamente, el diseño sigue principios sólidos de programación orientada a objetos en lugar de un script plano: existe una interfaz abstracta FileReader con implementaciones concretas para Excel (ExcelFileReader) y CSV (CSVFileReader), de modo que agregar soporte para un nuevo formato en el futuro no requiere tocar el resto del sistema. Un FileReaderManager decide en tiempo de ejecución qué lector usar según la extensión, y un FileValidator filtra archivos inexistentes, vacíos o con extensión no soportada antes de procesarlos. El manejo de CSV es especialmente robusto: prueba automáticamente varias codificaciones (UTF-8, Latin-1, ISO-8859-1, CP1252) hasta encontrar la que permite leer el archivo sin errores, algo frecuente cuando los archivos provienen de sistemas o exportes distintos.

La clase principal ExcelUnifier ofrece tres modos de unificación seleccionables desde la interfaz: mantener todas las hojas de todos los archivos como hojas independientes en el libro final, consolidar todo el contenido en una sola hoja (útil cuando todos los archivos comparten la misma estructura de columnas), o unificar internamente las hojas de cada archivo pero conservando la separación entre archivos distintos. Todo el procesamiento corre en un hilo separado del hilo principal de la interfaz, así que la ventana no se congela mientras se procesan archivos grandes, y una barra de progreso con callback reporta en vivo qué archivo se está leyendo y qué porcentaje del lote se ha completado.

El manejo de errores está resuelto con una jerarquía de excepciones propia (InvalidFileException, InvalidFolderException, UnificationException, EncodingException) en lugar de excepciones genéricas, lo que permite que la interfaz muestre mensajes claros y específicos según lo que falló, sin detener el procesamiento del resto del lote cuando un solo archivo tiene un problema. Un logger centralizado (LoggerConfigurator) registra cada paso tanto en consola como opcionalmente en archivo, con niveles DEBUG/INFO diferenciados, lo que facilita diagnosticar por qué un archivo en particular no se incluyó en el resultado final.

Stack: Python, Tkinter + ttk, tkinterdnd2 (drag & drop), pandas, openpyxl, threading para procesamiento asíncrono, diseño orientado a objetos con clases abstractas, enums y dataclasses, logging y manejo de excepciones personalizado.
